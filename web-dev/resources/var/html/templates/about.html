About Pergamon

Pergamon is a platform for exploring and learning about retro computers. It is being made with the itent to preserve computer history at the University of New Haven. Planned features include virtual exhibits, a basic lesson system to teach old programming languages, CtF-like challenges, and a general playground to explore various old systems that ran at UNH. This is a prototype so far, but hopefully things continue to improve!
